# 📝 Task Management System

My Task Management System is a simple and user-friendly web-based application designed to manage daily tasks, organize work, and track task completion efficiently.

It provides an interactive interface for users to create, update, delete, and manage their tasks, helping them improve productivity and stay organized.

---

🔗 **Live Demo   :** [https://madhan-03.github.io/task-management/]  
🔗 **GitHub Repo :** [https://github.com/Madhan-03/task-management/]

---

# 🚀 Features

- 📱 Fully Responsive Modern Design.  
- ➕ Create New Tasks.  
- 📋 View and Manage All Tasks.  
- ✏️ Update Existing Tasks.  
- 🗑️ Delete Tasks.  
- ✅ Mark Tasks as Completed.  
- 📅 Manage Task Deadlines.  
- 🎯 Set Task Priorities.  
- 🔍 Track Task Status.  
- 💾 Store and Manage Task Information.  
- 🎨 User-Friendly Interface.
